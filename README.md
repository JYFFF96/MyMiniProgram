# MyMiniProgram - 宝宝成长纪念册

一个用于记录小朋友成长照片、视频和故事的微信小程序。

## 第一版功能

- 成长时间轴：首页按日期浏览成长记录
- 相册：按日常、生日、旅行、里程碑分类
- 发布记录：选择照片/视频并填写文字
- 宝宝档案：基本资料、数据统计、成长里程碑
- 我的：家庭成员、云端空间、隐私入口

当前版本主要完成前端原型和交互骨架，数据为演示数据。

## 打开方式

1. 安装并打开微信开发者工具。
2. 导入本仓库根目录。
3. 没有正式 AppID 时可使用测试号/游客模式。
4. 编译即可预览五个主要页面。
